# Countdown Timer

Aplicación web de cuenta regresiva desarrollada con JavaScript.

## Descripción

Countdown Timer permite seleccionar una fecha y hora para iniciar una cuenta regresiva en tiempo real.

La aplicación calcula automáticamente cuánto tiempo falta para el evento y actualiza los días, horas, minutos y segundos cada segundo.

Cuando la cuenta llega a cero, se muestra un mensaje indicando que el evento ha comenzado.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript

## Funcionalidades

- Selección de fecha y hora
- Cuenta regresiva en tiempo real
- Actualización automática cada segundo
- Cálculo de días, horas, minutos y segundos
- Mensaje final al terminar la cuenta
- Diseño responsive
- Interfaz moderna estilo futurista/neón
